The Substitution Method for Recurrence Relations

A comprehensive academic guide to iterative expansion, algebraic unrolling, base-case evaluation, and asymptotic complexity analysis for B.Tech CSE/AIML students.

📖

1. What is a Recurrence Relation?

In computer science and algorithm design, a recurrence relation is an equation or inequality that defines a function $T(n)$ in terms of its value on smaller inputs.

$$T(n) = a \cdot T\left(\frac{n}{b}\right) + f(n) \quad \text{or} \quad T(n) = a \cdot T(n-k) + f(n)$$

Recurrence relations are used in Design and Analysis of Algorithms (DAA) to mathematically model the execution time and resource complexity of recursive algorithms like MergeSort ($2T(n/2) + n$), Binary Search ($T(n/2) + 1$), and Tower of Hanoi ($2T(n-1) + 1$).

⚡

2. The Substitution (Iterative Expansion) Method

The Substitution Method (also known as the Method of Iteration or Unrolling) is a fundamental technique where we repeatedly replace the recursive call $T(\cdot)$ with its algebraic definition until a clear mathematical pattern emerges after $k$ steps.

Step 1

Repeated Algebraic Expansion

Substitute $T(n-1)$ or $T(n/b)$ into the original equation for steps 1, 2, and 3 without prematurely multiplying terms together so patterns remain visible.

$$T(n) = 2T(n/2) + n = 2[2T(n/4) + n/2] + n = 4T(n/4) + 2n$$
Step 2

Identify the General $k$-th Pattern

Formulate an equation expressing $T(n)$ in terms of an arbitrary parameter $k$:

$$T(n) = 2^k T\left(\frac{n}{2^k}\right) + k \cdot n$$
Step 3

Reach the Base Case & Solve for $k$

Equate the inner subproblem to the base case value $n_0$ (typically $1$ or $0$):

$$\frac{n}{2^k} = 1 \implies 2^k = n \implies k = \log_2 n$$
Step 4

Substitute $k$ & Evaluate Closed Form

Replace $k$ and $T(1)$ into the general formula to obtain the exact analytical function and extract the dominant term:

$$T(n) = n \cdot T(1) + n \log_2 n = n \log_2 n + n = \Theta(n \log n)$$
💡

3. Advantages of the Substitution Method

  • Provides Exact Closed-Form Equations: Unlike generic upper-bound formulas, substitution yields the exact function $T(n)$ with all constant multipliers and lower-order terms.
  • Solves Decrement Recurrences: Decrement recurrences like $T(n) = T(n-1) + n$ or $T(n) = 2T(n-1) + 1$ cannot be solved by the standard Master Theorem, but are straightforward with substitution.
  • Deep Mathematical Understanding: Unrolling reveals how work is distributed across recursion levels, giving students clear intuition for algorithm design.
  • Exam & Viva Essential: University exam questions in B.Tech DAA specifically request step-by-step unrolling derivations.

4. Classic Recurrence Reference Summary

Algorithm / Problem Recurrence Relation Exact Formula $T(n)$ Tight Bound $\Theta$
Binary Search $T(n) = T(n/2) + 1$ $1 + \log_2 n$ $\Theta(\log n)$
MergeSort $T(n) = 2T(n/2) + n$ $n \log_2 n + n$ $\Theta(n \log n)$
Tower of Hanoi $T(n) = 2T(n-1) + 1$ $2^n - 1$ $\Theta(2^n)$
Insertion / Selection Sort $T(n) = T(n-1) + n$ $\frac{n(n+1)}{2}$ $\Theta(n^2)$
Linear Scan / Decrement $T(n) = T(n-1) + 5$ $5n - 4$ $\Theta(n)$
