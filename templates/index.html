Divide-by-Constant

T(n) = 2T(n/2) + n $\Theta(n \log n)$

Balanced divide and conquer with linear combine work at each level.

T(n) = T(n/2) + 1 $\Theta(\log n)$

Halving problem size with constant step work.

Binary subproblem branching with constant combine cost.

Different Bases ($b = 3$)

T(n) = T(n/3) + n $\Theta(n)$

Divide by 3 with linear combine work ($a < b$, root dominates).

T(n) = 2T(n/3) + n $\Theta(n)$

T(n) = 4T(n/3) + n^2 $\Theta(n^2)$

Quadratic work, ratio $4/9 < 1$, root quadratic dominates.

Exponential branching decrement unrolled to geometric series.

💡 Educational Guide

How the Substitution Method Works

The rigorous mathematical steps used to solve recurrence relations through iterative expansion.

1
📝

Write the Recurrence

State the original relation $T(n)$ along with the base case boundary condition $T(n_0) = b_0$.

$$T(n) = 2T(n/2) + n$$
2
🔄

Substitute Repeatedly

Substitute $T(n/b)$ or $T(n-c)$ using the definition to unroll recursive calls.

$$T(n) = 4T(n/4) + 2n$$
3
🔍

Find the Pattern

Express the relation after $k$ iterative substitutions as a general $k$-th formula.

$$T(n) = 2^k T(n/2^k) + kn$$
4
🎯

Stopping Condition

Set the inner subproblem equal to base index $n_0$ (e.g., $n/2^k = 1$) to solve for $k$.

$$k = \log_2 n$$
5
✨

Substitute k & Simplify

Substitute $k$ and the base case value $T(1)$ back into the formula to produce the closed form.

$$T(n) = n \log_2 n + n$$
6
📊

Determine Complexity

Identify the dominant term to establish the asymptotic tight bound ($\Theta$).

$$\Theta(n \log n)$$
